# Artwork licensing

The relay-arrow SVG masters and platform icon assets in [`assets/icon/`](../assets/icon/) are covered by the repository MIT license. They do not contain an exported Apple system symbol. Trademark clearance has not been performed.

Keep application artwork separate from system-provided interface symbols. Apple restricts use of its system images in app icons, logos, and trademarks; see the [Xcode and Apple SDKs Agreement, section 2.10](https://images.apple.com/legal/sla/docs/xcode.pdf).

See the [icon asset instructions](../assets/icon/README.md) to regenerate exports and update signed bundles.
