# sudo-relay icon

The owner selected the original custom design on November 10, then requested
a simpler empty shield on November 11. The dots and connecting line are removed;
the custom shield outline remains. This does not restore the earlier Apple
system-symbol export.
`sudo-relay.svg` is the editable source; `preview.png` is the preview.
The macOS ICNS is generated from that SVG by the native bundle packager.
Linux can use the same SVG; desktop integration remains untested.

The artwork is covered by the repository MIT license. No Apple SF Symbol is
exported into these assets. See [source review](../../docs/icon-source-review.md).
